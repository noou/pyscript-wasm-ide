# PyScript WASM IDE

Легковесная среда разработки (IDE) для Python, работающая полностью в браузере. Проект использует **PyScript** и **WebAssembly (WASM)** для исполнения кода на стороне клиента без необходимости в бэкенде.

## 🚀 Основные возможности

* **Исполнение в браузере:** Код выполняется через WASM, не требуя установки Python на компьютер.
* **Подсветка синтаксиса:** Реализована через Prism.js с кастомным слоем синхронизации для `textarea`.
* **Два режима ввода:** Полноценный многострочный редактор и отдельная строка для быстрых REPL-команд (>>>).
* **Автосохранение:** Весь написанный код сохраняется в `localStorage` и доступен после перезагрузки страницы.
* **Экспорт кода:** Быстрая выгрузка текущего скрипта в файл `.py`.
* **Горячие клавиши:** Поддержка `Tab` для отступов и `Ctrl + Enter` для запуска кода.

## 🛠 Технологический стек

* **PyScript (v2024.1.1):** Для запуска Python в вебе.
* **Prism.js:** Для динамической подсветки синтаксиса.
* **JavaScript:** Для управления DOM, синхронизации скролла и работы с локальным хранилищем.
* **CSS3:** Темная тема в стиле VS Code.

## 📦 Быстрый старт

1. Склонируйте репозиторий или просто скачайте файл `index.html`.
2. Откройте `index.html` в любом современном браузере.
3. Дождитесь инициализации среды PyScript (в консоли появится надпись "Консоль готова").
4. Пишите код и нажимайте **▶ ЗАПУСТИТЬ**.

## 📝 Особенности реализации

В проекте решена проблема синхронизации прозрачного `textarea` и слоя подсветки `pre/code`, что позволяет редактировать код с полноценным синтаксическим оформлением, сохраняя стандартное поведение текстового поля.
